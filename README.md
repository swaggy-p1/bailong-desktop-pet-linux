# Bailong Desktop Pet Linux

Linux 适配版：基于 PySide6 的透明动态桌宠，支持互动、拖动、托盘菜单、可选 Codex 对话和 XDG 用户级自启动。完整压缩包和校验文件见 [v0.1.0 Release](https://github.com/swaggy-p1/bailong-desktop-pet-linux/releases/tag/v0.1.0)。

本项目基于原项目 **bailong-desktop-pet** v0.4.1 的公开 Python 源码和官方发布包动画素材制作：

- 原项目作者 / GitHub 账号：`jingh12312-rgb`
- 原项目仓库：https://github.com/jingh12312-rgb/bailong-desktop-pet

归属和素材许可说明见 [ATTRIBUTION.md](ATTRIBUTION.md)，Linux 安装部署见 [DEPLOYMENT.md](DEPLOYMENT.md)。
